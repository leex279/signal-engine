# 2026-10-17 - Claude Code adds auto-mode model selection, Ollama ships decision models in CLI, HyperFrames improves preview performance

## Releases & Changelogs

- **Claude Code v2.1.302 adds `CLAUDE_CODE_AUTO_MODE_MODEL` to choose which model runs the client-side auto mode classifier** - You can now control the model that decides when to enter auto mode without changing the model that runs server-side auto mode, and idle compaction can be toggled in `/config`. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

- **Claude Code v2.1.301 adds `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` to end unattended retry requests at distant usage limit resets** - Unattended retry mode now stops waiting if the usage limit reset is too far away, and the release adds OpenTelemetry tracing guidance to the `claude-api` skill. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)

- **Claude Code v2.1.300 adds `virtualText` to mod prompt decorations and `$.ui.view({ agentId })` for showing agent transcripts** - Mods can now draw text in the prompt box that never enters the draft or submitted prompt, and OpenTelemetry `api_request` events split cache writes by 5m and 1h lifetimes. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)

- **Claude Code v2.1.299 adds `CLAUDE_CODE_DISABLE_FILE_MENTIONS` and idle compaction for long conversations** - File mentions now send paths instead of contents when this flag is set, and conversations over 200K tokens idle for ~54 minutes are compacted before the one-hour prompt cache expires. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)

- **OpenAI Codex rust-v0.163.0 adds `/config` search across preferences and follow-up messages while Codex is responding** - You can now search all settings, change supported ones immediately, see which need a restart, and send follow-ups to steer Codex mid-response (interrupting also stops Code Mode cells). [source](https://github.com/openai/codex/releases/tag/rust-v0.163.0)

- **Ollama v0.40.4 brings decision models to the CLI with `ollama run` for yes/no questions, classification, and scoring** - Kev decision models now run on Apple silicon with the MLX runner, and you can pipe text to classify or score against a rubric directly from the terminal. [source](https://github.com/ollama/ollama/releases/tag/v0.40.4)

- **Ollama v0.40.5 adds NVIDIA Nemotron 3.5 Super, a 120B-parameter vision-language model with 12B active per token** - This hybrid Mamba-2/Transformer mixture-of-experts model supports coding, reasoning, tool use, and document understanding with a C-RADIO vision encoder. [source](https://github.com/ollama/ollama/releases/tag/v0.40.5)

- **HyperFrames v0.8.167 makes long project previews smoother by following what is playing instead of total clip count** - Preview work now tracks the playing position rather than the full clip list, and bundling a project no longer blocks the host thread on esbuild. [source](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.167)

- **HyperFrames v0.8.160 adds `hyperframes audio` command to measure sound timing and improves Windows rendering** - You can now measure audio onsets, peaks, pauses, and loudness, and project queries report film timing; trimmed-video previews, Claude usage reporting, and element picking also improved. [source](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.160)

- **HyperFrames v0.8.161 finds music beats without launching Chrome using TypeScript beat tracker through FFmpeg** - Beat detection now runs through FFmpeg decoding without Chrome, and TypeScript projects using NodeNext can resolve the published package declarations. [source](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.161)
