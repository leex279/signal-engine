# 2026-10-17 - Claude Code adds auto-mode model selection, Codex ships in-chat config search, HyperFrames measures audio timing

## Releases & Changelogs

- **Claude Code v2.1.302 adds `CLAUDE_CODE_AUTO_MODE_MODEL` to choose which model runs the client-side auto mode classifier** - The setting does not change the model for server-side auto mode, and you can now turn idle compaction on or off in `/config`. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

- **Claude Code v2.1.301 adds `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` so unattended retry mode ends a request at a usage limit that resets too far away** - The release also adds OpenTelemetry tracing guidance to the `claude-api` skill and the `%` motion to vim mode. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)

- **Claude Code v2.1.300 adds `virtualText` to a mod's prompt decorations** - Text drawn in the prompt box never enters the draft or the submitted prompt, and mods can now call `$.ui.view({ agentId })` to show an agent's transcript in a panel. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)

- **Claude Code v2.1.299 adds `CLAUDE_CODE_DISABLE_FILE_MENTIONS` so Claude gets paths of `@` file mentions to read with its file tools, not the files' contents** - Idle compaction now runs on conversations left idle for about 54 minutes before the one-hour prompt cache expires. [source](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)

- **OpenAI Codex rust-v0.163.0 ships `/config` to search preferences across categories, change supported settings immediately, and see which changes require a restart** - You can now send a follow-up while Codex is responding to steer it immediately, and interrupting a turn stops active Code Mode cells and their nested tool calls. [source](https://github.com/openai/codex/releases/tag/rust-v0.163.0)

- **HyperFrames v0.8.160 adds `hyperframes audio` to measure audio onsets, peaks, pauses, and loudness** - Project queries now report film timing, and the release improves trimmed-video previews, Windows rendering, Claude usage reporting, history saves, and element picking. [source](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.160)

- **HyperFrames v0.8.167 makes long projects preview more smoothly by following what is playing, not the total clip count** - Bundling a project no longer blocks the host's thread on esbuild. [source](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.167)

- **Ollama v0.40.4 adds decision models to the CLI** - Run `ollama run nimble --ask "Is a refund being requested?" < ticket.txt` to ask yes/no questions, classify text into labels, or score against a rubric. [source](https://github.com/ollama/ollama/releases/tag/v0.40.4)

- **Ollama v0.40.5 ships NVIDIA Nemotron 3.5 Super, a vision-language model for coding, reasoning, tool use, and document understanding** - The 120B-parameter hybrid Mamba-2/Transformer mixture-of-experts backbone (12B active per token) pairs with a C-RADIO vision encoder and supports tool calling. [source](https://github.com/ollama/ollama/releases/tag/v0.40.5)

- **Gemini CLI v0.65.0-preview.0 enforces read-only workspace settings in untrusted folders** - The release also avoids duplicate tool response turns when resuming sessions and prevents deletion of active session files. [source](https://github.com/google-gemini/gemini-cli/releases/tag/v0.65.0-preview.0)
